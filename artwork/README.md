# Artwork

The `minix.ascii` file contains an ANSI true-color adaptation of Rocky Raccoon, the MINIX 3 mascot.

## Original artwork

- **Title:** Rocky Raccoon mascot of MINIX 3
- **Author:** MINIX (as credited by Wikimedia Commons)
- **Source:** https://commons.wikimedia.org/wiki/File:Rocky_Raccoon_mascot_of_MINIX_3.jpg
- **License:** Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
- **License URL:** https://creativecommons.org/licenses/by-sa/4.0/

## Modifications

The original JPEG image was modified by Number_51 in two stages:

1. The background was removed to produce a PNG image with a transparent background.
2. The PNG was converted into ANSI-colored text using `jp2a`.

Only the resulting `minix.ascii` file is included in this repository. The original JPEG and intermediate PNG are not distributed.
